# Phase 0 Acceptance Checklist

Phase 0 is complete when:

- [x] Canonical IDs are defined.
- [x] Canonical event names are defined.
- [x] Core state machines are defined.
- [x] No network target needs to be hardcoded.
- [x] Local PoC target profile exists.
- [x] External recorder template exists.
- [x] RTP/RTCP ranges are configurable.
- [x] Media/protocol defaults are explicit.
- [x] Logging aggregation policy is explicit.
- [x] Recording watermarks are part of the common contract.
- [x] Deterministic smoke scenario format is seeded.

Deferred gates:
- Exact MXF operational profile/toolchain: Phase 2 spike.
- Exact ED-137/recorder metadata mapping and method ordering: interoperability phase.
- Production security/HA/PKI: outside PoC.
